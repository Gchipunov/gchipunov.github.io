When an autonomous coding loop initializes—whether running inside agent_studio.html (Browser JS), ollama_pi_agent.py (Raspberry Pi Zero Python 3), or agent_loop.cpp (C++11/17)—it follows a deterministic two-request handshake. First, it queries the local or LAN Ollama daemon to resolve the active model tag; second, it dispatches a single structured POST /api/chat request containing the role constraints, the task prompt, and the current source code snapshot.

1. Step 1: Model Discovery (GET /api/tags)

Rather than hardcoding a model string that might not exist on the host machine, the loop starts by sending an HTTP GET request to /api/tags. Ollama returns a JSON manifest of all locally pulled weights. 

// HTTP Request
GET http://localhost:11434/api/tags HTTP/1.1
Accept: application/json

// HTTP Response (200 OK)
{
  "models": [
    {
      "name": "qwen2.5-coder:latest",
      "size": 4683075271,
      "details": { "family": "qwen2", "parameter_size": "7.6B" }
    }
  ]
}

The orchestrator extracts response.models[0].name (e.g., "qwen2.5-coder:latest") and assigns it to both the Coder Agent and the Reviewer Agent for Iteration #1.

2. Step 2: Constructing the Single Prompt with Embedded Code

In Iteration #1, the loop combines three pieces into a single user message: the shared problem goal, the output formatting rule, and the starter RTS source code wrapped in fenced markers.

Message Role Purpose in Loop Content Structure
system Enforces language & output boundaries Instructs the model to return only valid WebGL HTML/JS or C++11 inside a single fenced code block without prose truncation.
user Delivers 1 prompt + baseline code Concatenates the task description, the [jscode] format directive, and the starter 3-building / 3-unit code.

3. Step 3: Executing POST /api/chat (Exact Wire Payload)

Below is the exact JSON body transmitted by the loop script on its very first coding iteration. Setting "stream": false ensures Ollama buffers the entire generated file and returns a single parseable JSON object. 

POST http://localhost:11434/api/chat HTTP/1.1
Content-Type: application/json

{
  "model": "qwen2.5-coder:latest",
  "stream": false,
  "options": {
    "temperature": 0.25
  },
  "messages": [
    {
      "role": "system",
      "content": "You are an expert WebGL and JavaScript RTS game engine programmer. Write a complete, self-contained single-file HTML5 + WebGL game featuring 3 structures (Command Center, Power Plant, War Factory) and 3 units (MCV, Crusader Tank, Ranger Squad). Output ONLY valid HTML inside ```html ... ```."
    },
    {
      "role": "user",
      "content": "SHARED PROBLEM:\nBuild a playable WebGL RTS mini-game with 3 structures and 3 units with mouse selection and move orders.\n\nREQUIRED FORMAT INSTRUCTION:\nmake webgl single html static file of this game after your done coding with description: 3 units and 3 structures based off some status rts game code:\n```html\n<!DOCTYPE html>\n<html><body><canvas id='gl'></canvas><script>\nconst structures = ['Command Center', 'Power Plant', 'War Factory'];\nconst units = ['MCV', 'Crusader Tank', 'Ranger Squad'];\n// ... starter WebGL render loop ...\n</script></body></html>\n```"
    }
  ]
}
Why temperature: 0.25? Low temperature prevents the model from inventing non-existent WebGL extensions or renaming the 3 required structures and 3 units between iterations, keeping the Reviewer Agent's checks predictable.

4. Step 4: Parsing the Response & Advancing the Loop

Ollama responds with the generated assistant message inside message.content. The loop extracts the code between ```html and ```, passes it to Agent 2 (Reviewer), and hot-reloads the viewport. 

// JSON Returned by Ollama
{
  "model": "qwen2.5-coder:latest",
  "done": true,
  "message": {
    "role": "assistant",
    "content": "```html\n<!DOCTYPE html>\n<html>... full updated WebGL RTS code ...</html>\n```"
  }
}

// Loop Extraction Logic (JavaScript)
const rawReply = data.message.content;
const match = rawReply.match(/```(?:html)?\s*\n([\s\S]*?)```/i);
const candidateCode = match ? match[1].trim() : rawReply.trim();
